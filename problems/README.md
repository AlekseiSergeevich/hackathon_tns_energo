# Журнал проблем

Здесь собраны проблемы, найденные в данных, коде и договорённостях: что не так, на что влияет, как воспроизвести и что с этим делаем. Одна проблема = один файл.

Зачем: чтобы находки не терялись в чатах, чтобы любой из команды мог за минуту проверить проблему своими глазами, а для заказчика и конференции был готовый список «что нашли в данных».

## Список

| № | Проблема | Где | Влияет на | Статус |
|---|---|---|---|---|
| [001](001-court-application-ls-na.md) | В файле 12 у 41 % строк вместо ЛС стоит `#N/A` | данные, файл 12 | стадии S4–S5, признаки ML | ждём заказчика |
| [002](002-measure-repeats.md) | Повторы строк в журналах мер 04–13 | данные, файлы 04–13 | стадии, признаки ML, отчёт о качестве | обойдено, ждём заказчика |

## Как добавить проблему

1. Взять следующий номер, создать файл `NNN-kratko-latinicey.md` (латиница в имени: без проблем на Windows).
2. Заполнить по шаблону ниже. Код воспроизведения запускается из корня репозитория (`.venv/bin/python` или `python`) и читает исходные файлы напрямую, без кода из `tns/`: так проверка не зависит от того, правильно ли работает наш код.
3. Добавить строку в таблицу выше.
4. Когда статус меняется, обновить и файл, и таблицу. Решённые проблемы не удалять.

**Статусы:** `открыта` → `ждём заказчика` / `в работе` → `обойдено` (временное решение в коде) → `решена`.

## Шаблон

```markdown
# NNN. Короткое название

| | |
|---|---|
| Статус | открыта |
| Найдено | ГГГГ-ММ-ДД, кто, при какой работе (задача) |
| Где | файл / модуль / функция |
| Влияет на | данные / правила / ML / аллокатор / отчёты |
| Ответственный | кто решает |
| Связано | задачи (DATA-2, ML-1…), риски из плана (D5…), вопросы заказчику |

## Что не так
Суть в 2–3 предложениях, с цифрами.

## Примеры
Конкретные строки из данных или вывод кода.

## Как воспроизвести
Код (если есть) и что он должен напечатать.

## Почему это важно
На что влияет и насколько сильно.

## Что делаем сейчас
Временное решение в коде, если есть, и где оно.

## Что нужно, чтобы закрыть
Вопрос заказчику / задача кому-то из команды.
```
