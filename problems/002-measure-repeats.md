## Что не так

В журналах мер у одного ЛС бывает несколько строк одной меры в одном месяце. Повторы бывают трёх видов, и смысл у них, судя по всему, разный:

1. **Точная копия строки** (тот же ЛС, та же дата). В файле 12 каждое заявление записано минимум дважды.
2. **Несколько действий за месяц у мер с точностью «месяц».** У автодозвона и e-mail дата всегда 1-е число, поэтому несколько звонков или писем за месяц выглядят как копии.
3. **Несколько дат в одном месяце.** Например, у уведомлений об ограничении — до 4 уведомлений в месяц с разными днями.

## Примеры

Сводка по файлам (строки без ЛС из [001](001-court-application-ls-na.md) уже исключены):

| Файл | Строк с ЛС | Точные повторы ЛС + дата | Ещё дата в том же месяце | Осталось «ЛС × месяц» | Доля повторов |
|---|---|---|---|---|---|
| 04 Автодозвон | 113 319 | 27 739 | 0 | 85 580 | 24,5 % |
| 05 E-mail | 69 058 | 21 629 | 0 | 47 429 | 31,3 % |
| 06 СМС | 30 419 | 0 | 0 | 30 419 | 0 |
| 07 Обзвон | 21 849 | 0 | 0 | 21 849 | 0 |
| 08 Претензия | 5 779 | 3 | 0 | 5 776 | 0,1 % |
| 09 Выезд | 6 906 | 197 | 177 | 6 532 | 5,4 % |
| 10 Уведомление | 86 681 | 354 | 3 514 | 82 813 | 4,5 % |
| 11 Ограничение | 2 484 | 0 | 0 | 2 484 | 0 |
| 12 Заявление в суд | 8 390 | 4 206 | 8 | 4 176 | **50,2 %** |
| 13 Приказ / ИЛ | 3 320 | 17 | 11 | 3 292 | 0,8 % |
| **Итого** | 348 205 | | | 290 350 | 16,6 % |

**Вид 1 — файл 12, точные копии.** 4 173 пары «ЛС + дата» встречаются ровно 2 раза, ещё 11 пар — 4 раза. Если у ЛС одно заявление, копия стоит следующей строкой; если несколько, повторяется весь набор целиком:

```
  №      ЛС      Дата
  0      66      2025-07-30
  1      66      2025-07-30    ← копия
  2      90      2025-11-24
  3      90      2025-11-24    ← копия
  ...
  8384   147017  2025-02-24
  8385   147017  2025-05-30
  8386   147017  2026-02-04
  8387   147017  2025-02-24    ← набор из трёх заявлений повторён
  8388   147017  2025-05-30
  8389   147017  2026-02-04
```

(№ — номер строки данных от 0, без двух строк шапки, как в [001](001-court-application-ls-na.md).) Похоже на дубль выгрузки: например, соединение таблиц, в котором у каждого заявления нашлось по две записи.

Это не то же самое, что повторные обращения в суд: у 857 ЛС из 3 174 заявления стоят в **разных** месяцах, это отдельные события.

**Вид 2 — автодозвон.** У одного ЛС бывает до 6 строк с датой 1-го числа одного месяца: 19 475 пар встречаются 2 раза, 3 203 — 3 раза, 489 — 4, 84 — 5, 11 — 6. Пример, ЛС 90:

```
  ЛС  Дата
  90  2025-04-01
  90  2025-07-01
  90  2025-07-01    ← два автодозвона в июле
```

**Вид 3 — уведомления об ограничении.** 3 323 случая, когда у ЛС в одном месяце несколько разных дат уведомления. Между первой и последней датой в среднем 12 дней (медиана 15, до 27). Пример, ЛС 27, февраль 2025: 13, 14, 18 и 26 февраля. Это дополняет риск D8 («уведомления повторяются каждый месяц»): повторы бывают и внутри месяца.

## Как воспроизвести

```python
from pathlib import Path
import pandas as pd

DATA = Path("Материалы к кейсу")
FILES = {
    "04 Автодозвон": "04 Автодозвон ХК.xlsx",
    "05 E-mail": "05 E-mail ХК.xlsx",
    "06 СМС": "06 СМС ХК.xlsx",
    "07 Обзвон": "07 Обзвон оператором ХК.xlsx",
    "08 Претензия": "08 Претензия ХК.xlsx",
    "09 Выезд": "09 Выезд к абоненту ХК.xlsx",
    "10 Уведомление": "10 Уведомление о введении ограничения ХК.xlsx",
    "11 Ограничение": "11 Ограничение ХК.xlsx",
    "12 Заявление в суд": "12 Заявление о выдаче судебного приказа ХК.xlsx",
    "13 Приказ / ИЛ": "13 Получение судебного приказа или ИЛ ХК.xlsx",
}


def load(file):
    raw = pd.read_excel(DATA / file, header=None).iloc[2:, :2]  # строки 1–2: название меры и «ЛС | Дата»
    df = pd.DataFrame({"ls": pd.to_numeric(raw[0], errors="coerce"),
                       "date": pd.to_datetime(raw[1], errors="coerce")}).dropna()
    df["ls"] = df["ls"].astype("int64")
    df["month"] = df["date"].dt.to_period("M")
    return df


rows = []
for name, file in FILES.items():
    df = load(file)
    uniq_day = df.drop_duplicates(["ls", "date"])
    rows.append({
        "файл": name,
        "строк с ЛС": len(df),
        "точные повторы": len(df) - len(uniq_day),
        "ещё дата в месяце": len(uniq_day) - len(uniq_day.drop_duplicates(["ls", "month"])),
        "ЛС × месяц": len(df.drop_duplicates(["ls", "month"])),
    })
print(pd.DataFrame(rows).to_string(index=False))

# Вид 1: файл 12, сколько раз повторяется пара ЛС + дата
court = load(FILES["12 Заявление в суд"])
print(court.groupby(["ls", "date"]).size().value_counts().sort_index())   # 2: 4173, 4: 11
print(court[court["ls"] == 147017])

# Вид 3: уведомления с несколькими датами в одном месяце
notice = load(FILES["10 Уведомление"])
print(notice[(notice["ls"] == 27) & (notice["month"] == "2025-02")])
```

## Почему это важно

- **Стадии (Аня).** Если считать каждую строку отдельным событием, ЛС «получит» два заявления в суд в один день или четыре уведомления за месяц. Для переходов T-2→3, T-3→4 и условия R-NTC-01 («уведомление в цикле ещё не направлялось») нужна именно первая дата.
- **ML.** Признаки вида «сколько раз применялась мера» без свёртки завышены для автодозвона и e-mail на 25–30 %.
- **Лимиты.** Если меры считать по строкам, исторически лимит автодозвона и e-mail выглядит перевыполненным.
- **Отчёт о качестве (DATA-3)** должен показывать эти цифры заказчику.

## Что делаем сейчас

По договорённости в `docs/interfaces.md` (раздел `measure_events`): мера по ЛС вводится не чаще раза в месяц, несколько строк одной меры в одном месяце сворачиваются в одну. `event_date` — первая дата в месяце, `n_raw` — сколько строк было в файле. Реализовано в `tns/ml/proto_panel.py`, функция `load_measure_events`, в лог пишется «Журнал мер: 57 855 повторных строк в том же месяце свёрнуто».
